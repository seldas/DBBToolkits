Got a Connection / CORS Error?

Browsers restrict requests to different ports/domains (CORS). If connecting to local Ollama:

  • macOS: Run launchctl setenv OLLAMA_ORIGINS "*" in terminal, then restart Ollama.
  • Windows: Close Ollama from system tray, run set OLLAMA_ORIGINS=* in cmd, then launch ollama serve.
  • Linux: Run systemctl edit ollama.service, add Environment="OLLAMA_ORIGINS=*", then run systemctl daemon-reload && systemctl restart ollama.
