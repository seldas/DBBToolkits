# DBBtoolkits — Scientific Research Tool Suite

[![Release](https://img.shields.io/github/v/release/seldas/DBBToolkits?color=blue)](https://github.com/seldas/DBBToolkits/releases)
[![Platform](https://img.shields.io/badge/platform-Windows-blue)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**DBBtoolkits** is a premium, lightweight desktop application containing a suite of high-performance scientific tools designed to streamline daily research workflows. By wrapping a high-performance modern web interface in a native desktop shell using **Tauri v2** and **Rust**, DBBtoolkits operates completely offline and locally, ensuring maximum privacy for your papers, citations, and data.

## 🚀 Download & Install

For standard users on Windows, you can download the pre-compiled version directly:

## 🛠️ Core Toolkits

DBBtoolkits packs six essential scientific micro-utilities:

### 1. 📷 Figure DPI Converter
Prepare figures and images for journal submissions.
* Rewrites metadata resolution headers directly in-memory.
* Converts images to **72, 150, 300, or 600 DPI** without resizing or modifying pixel arrays (zero compression quality loss).
* Supports `PNG`, `JPEG`, and `TIFF`.

### 2. 🔠 BibTeX Citation Cleaner
Clean Google Scholar, PubMed, or citation manager exports for LaTeX.
* Strips redundant fields (such as `abstract`, `keywords`, `note`, `file`, `epub`, `url`, `issn`) while preserving `DOI`.
* Automatically wraps capitalized words in title blocks with curly braces (e.g., `{CNN}`, `{GPT-3}`) to prevent LaTeX from rendering them lowercase.
* Removes duplicate citations.

### 3. 🌐 LLM Toolkits & JSON Fixer
Integrate and debug local Large Language Models.
* **Server Connection Tester**: Test connectivity, query latency, and active model lists on local LLM servers (like Ollama, vLLM) or OpenAI-compatible endpoints.
* **CORS-Free execution**: By running inside a Tauri Rust wrapper, local network calls bypass standard browser Cross-Origin Resource Sharing (CORS) limits.
* **JSON Output Fixer**: Automatically repairs truncated or malformed JSON payloads generated by LLMs by closing quotes, objects, and arrays.

### 4. 🧮 Universal Table Converter
Convert Excel tables to Markdown documentation in seconds.
* Paste rows copied directly from Excel, CSV, or TSV formats to convert them into formatted, aligned Markdown tables.
* Easily convert Markdown tables back into tab-separated cells ready to paste back into Excel/Google Sheets.

### 5. 🔍 Local Privacy Diff Checker
Visually compare text changes.
* Compare drafts of abstracts, papers, or prompts side-by-side.
* Offers both line-by-line and word-by-word diff comparisons.
* 100% client-side computation ensuring secure data handling.

### 6. 📱 QR Code Generator
Generate clean QR codes for posters, presentations, or papers.
* Enter URLs (e.g., paper DOIs) and customize dimensions, error correction levels (L, M, Q, H), and foreground/background hex colors.
* Download as high-resolution PNGs.

## 💻 Developer Guide & Local Compilation

If you want to contribute, modify the code, or build the application from source:

### Prerequisites

1. **Node.js** (v18+)
2. **Rust Toolchain**:
   * Windows: Install [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (select *Desktop development with C++*) and [Rustup](https://rustup.rs/).

### Setup & Development

Clone the repository and install dependencies:

```powershell
# Clone the repository
git clone https://github.com/seldas/DBBToolkits.git
cd DBBToolkits

# Install dependencies
npm install
```

To run the application in Tauri desktop development mode with hot-reloading:

```powershell
npm run tauri dev
```

### Packaging a Release

To compile and package the production installer:

```powershell
npm run tauri build
```

The output installers will be built under [src-tauri/target/release/bundle/nsis/](file:///d:/Coding/DBBToolkits/src-tauri/target/release/bundle/nsis/) (`.exe`) and [src-tauri/target/release/bundle/msi/](file:///d:/Coding/DBBToolkits/src-tauri/target/release/bundle/msi/) (`.msi`).

## 🔒 Privacy & Security

All computations in DBBtoolkits occur locally on your machine.
* **No Telemetry**: We do not collect analytics, logs, or usage behaviors.
* **No Cloud Processing**: Your figures, BibTeX databases, and text comparisons never leave your computer.
* **Offline Ready**: The tool suite functions completely without an active internet connection.
